# Бот подписчиков для mikan

Telegram-бот подписчиков для панели [mikan](https://github.com/Miroshka000/mikan), сделанный из
официального бота mikan. Ставится как аддон прямо из этого репозитория. Всё, что умеет
официальный бот (подписка, устройства, покупка, пробный период, оплата, уведомления), остаётся,
и к этому добавляется:

- **Своё меню.** Меню собирается из разделов: у каждого раздела свой текст и кнопки. Кнопка
  открывает другой раздел или делает то, что умеет бот: показать подписку, продлить, купить,
  дать пробный период, открыть ссылку, Mini App или промокоды. Отдельно задаются главное меню
  для подписчиков и первый экран для новых людей. Кнопки, которым сейчас нечего делать,
  бот прячет сам: например, «Пробный период» после того, как пробник уже взят.
- **Рассылка всем.** Стандартная рассылка панели доходит только до тех, у кого есть подписка.
  Эта доходит до всех, кто хоть раз запускал бота. Получателей можно выбрать: все, с
  действующей подпиской, с закончившейся подпиской, без подписки. В сообщении могут быть
  картинка и кнопки. Рассылку можно запланировать на время, следить за прогрессом и
  остановить. После перезапуска бота она продолжается с того же места.
- **Автосообщения.** Бот пишет сам: через заданное время после первого запуска; если человек
  так и не оформил подписку; после оплаты; за заданное время до конца подписки и после конца
  (только если не продлил) — этот срок бот считает сам, не завися от напоминаний панели; когда
  кончается трафик. Сообщение о подписке можно ограничить тарифами.
- **Сообщения бота под вашим текстом.** Всё, что бот пишет сам (оплата, продление, возврат,
  пробный период не выдан, напоминания о конце, трафик), можно оставить стандартным, заменить
  своим — с картинкой и кнопками — или не отправлять вовсе.
- **Счётчики.** У каждого автосообщения, сообщения бота и рассылки видно, сколько раз оно ушло
  и сколько раз нажали его кнопки (кнопки-ссылки Telegram боту не сообщает, их не считает).
- **Оформление.** Иконки (свои эмодзи Telegram) и цвета кнопок, свои эмодзи в текстах.
- **Свои тексты** каждого экрана бота.

**Своей базы данных у бота нет.** Всё хранится в панели, в хранилище аддона: настройки, меню,
автосообщения, список чатов, задание рассылки, счётчики. Это попадает в резервные копии панели.
Ключ API панели не нужен: бот получает доступ через права, которые администратор даёт
аддону при установке.

## Установка

Нужна панель mikan **0.5.1.0** или новее.

1. В админке: **Аддоны → Источники → Добавить источник**, адрес
   `github.com/looksmm/mikan-subs-bot`. Если источник подписан, панель
   спросит ключ автора: он указан ниже.
2. В списке аддонов появится «Бот подписчиков» с пометкой «неофициальный» (так панель
   помечает все аддоны не из каталога mikan). Нажмите «Установить»: панель покажет права,
   которые просит аддон, — **«Одобрить и установить»**:

   | Право | Зачем |
   |---|---|
   | Бот | бот работает от имени бота панели, токен остаётся в панели |
   | Пользователи: чтение, изменение | экраны подписки, устройства, ссылка |
   | Все пользователи | рассылка по группам (с подпиской, без), автосообщения «не оформил», «не продлил» |
   | Оплата | покупка, пробный период, бесплатный тариф |
   | События | сообщения об оплате, уведомления, автосообщения |
   | Хранилище | настройки, меню, список чатов, рассылки |
   | Страницы | страница настроек в админке |

3. У аддона нажмите **«Отдать бота»**: бот панели начнёт работать через этот аддон. Вернуть
   официального бота можно той же кнопкой у него.
4. Настройки — на странице аддона в админке: вкладки «Меню», «Автосообщения», «Рассылка»,
   «Тексты и экраны», «Иконки и цвета».

Тарифы, способы оплаты, приветствие, кнопки стандартного меню и уведомления о сроке
по-прежнему настраиваются в панели («Telegram», «Платежи», «Тарифы»).

## Что важно знать

- **Список чатов бот собирает сам**, начиная с момента, когда ему отдан бот: каждого, кто
  пишет боту или нажимает кнопку. Подписчиков панели он добавляет сразу. Тех, кто запускал
  бота раньше, панель аддонам не отдаёт: их Telegram ID можно вставить во вкладке «Рассылка»
  → «Добавить чаты списком», например из базы панели:
  `SELECT tg_id FROM tg_chats WHERE blocked = 0`.
- Страница настроек следует теме системы: если тема админки mikan совпадает с темой
  компьютера, страница прозрачная и в тон панели.
- **Свои эмодзи** (иконки кнопок и эмодзи в текстах) Telegram показывает, только если у
  владельца бота есть Telegram Premium. Без него сообщения уходят без иконок, а страница
  покажет предупреждение. Цвета кнопок работают всегда.
- **Кнопки под рассылкой и автосообщением** открывают меню бота новым сообщением, само
  сообщение остаётся. Будет ли доступен, например, пробный период, бот проверяет в момент
  нажатия.
- Ночью (22:00–9:00 МСК) автосообщения и рассылки приходят без звука, если это включено в
  настройках бота в панели.

## Обновление

Новая версия — новый релиз этого репозитория. Панель увидит её в течение получаса
и предложит обновить аддон. Если новая версия просит новые права, панель покажет их перед
обновлением.

## Сборка и релиз (для автора)

Тег `v<версия>` (например `v1.0.0`) запускает `.github/workflows/release.yml`:

1. тесты;
2. образ для amd64 и arm64 в `ghcr.io/looksmm/mikan-subs-bot`;
3. релиз с `mikan-addon.json`: описание аддона (`addon.json`), версия, образ и его digest.

После первого релиза пакет в GitHub Packages нужно один раз сделать публичным
(**Package settings → Change visibility → Public**), иначе панели не скачают образ.

Подпись (по желанию): ключ делается командой `go run ./tools/sign -new`. Секретную часть
положите в секрет репозитория `MIKAN_ADDON_KEY`, публичную — в раздел «Установка» этого README.
Тогда каждый релиз выходит с `mikan-addon.json.sig`, и панель держит источник за этим ключом.

Id аддона задаётся в `addon.json` (поле `id`). Бот называет себя этим id: панель сверяет его
с описанием.

Локально: `go test -race ./...`; страницу можно посмотреть без панели:
`go run ./tools/pagedemo` (страница на `127.0.0.1:28480` с хранилищем в памяти).

Основа — официальный бот mikan версии из файла `UPSTREAM`; обновить её:
`python3 tools/sync_upstream.py <исходники mikan> <тег>`. Доработки — в пакете `internal/plus`
и файлах `plus_*.go`, а в коде mikan их места помечены `// plus:`.
